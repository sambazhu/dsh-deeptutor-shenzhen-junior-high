## 一、语法单选 25 题 · 按考点

| 考点 | 题号 | 答案 | 一句话规则 |
|---|---|---|---|
| **疑问词选择** | 1, 2, 3, 17 | B / C / C / A | 问地点 Where、问方式 How、问频率 **How often**、主语用 **Who** |
| **一般现在时三单** | 4, 5, 6, 7, 8 | C / B / B / A / B | 主语是三单 → 动词加 s/es；否定用 **doesn't + 原形** |
| **频度副词** | 6, 8 | never / on Sundays | 有 never/sometimes/often 用一般现在时；last Sunday 才用过去时 |
| **there be** | 10, 11, 12, 22, 23 | A / A / B / A / C | **就近原则**：离 be 最近的名词决定单复数；a number of + 复数 → are，the number of → is |
| **不可数名词** | 10, 12, 24 | grass / milk / as…as | grass、milk 不可数 → 用 is，不用 any 的复数形式 |
| **形容词 + be** | 9, 13, 16 | C / C / B | dangerous/windy/cloudy 是形容词，前面要有 be 动词或直接修饰名词 |
| **情态/将来** | 14, 19, 21 | C / A / C | will/bc + 原形；**if 条件句主将从现**；won't = will not |
| **It is + adj + to do** | 15 | C | it 作形式主语，真主语是不定式 |
| **比较级** | 24, 25 | B / B | not as + 原级 + as（不如）；人口用 **large/small**，不用 many |
| **宾语从句（真理）** | 20 | B | 客观真理永远用一般现在时 is |
| **口语固定表达** | 18 | B | Why me?（为什么是我） |

## 二、词形转换 35 题 · 按考点

| 考点 | 题号 | 答案 | 一句话规则 |
|---|---|---|---|
| **三单变形**（最集中） | 6, 7, 8, 9 | rides / washes / goes / brushes | every day / on Sundays / never / usually → 一般现在时；以 sh、ch、s、o 结尾加 es |
| **不定式 to do** | 1, 11, 13, 16, 21, 22, 32 | to watch / to keep / (to) sell / to drink / to protect ×2 / to make | want to do、help sb (to) do、It's adj to do、表目的用 to do、would like to do |
| **动名词 -ing** | 3, 17, 20, 34 | speaking / reading；listening / being / dancing | 介词后(at/about)、practice 后、并列作表语，都用 doing |
| **形容词 vs 副词** | 28, 27, 19 | strongly / daily / daily | 修饰动词（blows）用副词；修饰名词（life、newspaper）用形容词 |
| **-ed / -ing 分词形容词** | 26 | surprised；surprising | **人** 用 -ed（感到…），**物** 用 -ing（令人…） |
| **名词化** | 12, 23, 25, 30 | pollution / importance / owner / pollution | 主语/宾语位置要名词：important→importance、own→owner、pollute→pollution |
| **形容词化** | 18, 29, 31, 33 | old / interesting / important / better | be 动词后接形容词；the + adj 表一类人；than 前用比较级 good→better |
| **频度词** | 10, 35 | once / twice | 一次 once、两次 twice，后面接 a month / a week |
| **名词复数固定搭配** | 5 | friends | make **friends** with sb.（固定复数） |
| **后置定语** | 2 | called | 过去分词 called 放名词后 = "叫作…的" |
| **不可数不变形** | 24 | energy | energy 不可数，不加 s |

## 四、怎么用（家长操作）

1. **别按题号从头刷**，按上表"考点"一块一块看：一天只看 2 个考点（约 15 分钟）

4. 错题直接进 `03_英语/语法/语法知识点积累本.md`，标"规则/错例/钩子"三栏

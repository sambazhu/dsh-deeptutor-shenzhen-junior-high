# 英语作文自查卡（5 条）

> 用途：每次作文写完，花 5 分钟按这 5 条过一遍。
> 由来：2026-10-20 蓝天第二次课堂作文 10.5/15，扣分集中在“主谓一致 + 单词间距”。

## 写完后逐条打勾

- [ ] **① 主语单复数 → 动词形式对了吗？**
  - 主语单数：be 用 is，实义动词加 s/es（He **lives**、It **tells**）
  - 主语复数：be 用 are，动词用原形（My classes **are**）
  - 例：My favourite class **is** geography（不是 classes is）

- [ ] **② 每句话都有谓语动词吗？**
  - 例：I **love** geography as it lets me learn…（不能写成 I geography…）

- [ ] **③ 介词搭配对不对？**
  - hear … **from** sb.（不是 with）
  - be busy **with**
  - go **to** the club

- [ ] **④ 标点**
  - 问句用 **?**，陈述句用 **.**
  - 例：What about you**?**

- [ ] **⑤ 署名**
  - 写自己的名字 **Austin**，不是范文里的 Li Hua

## 卷面（单列，因为被扣了 0.5 分）

- [ ] 单词之间留空格：不能写 `aboutmy` / `Itisexciting` / `Ihave` / `inthe`
- [ ] 长句适当加逗号
- [ ] 少涂改，写错划一道线即可

## 常见错词

| 错 | 对 |
|---|---|
| aways | **always** |
| belive | **believe** |
| favourit | **favourite** |

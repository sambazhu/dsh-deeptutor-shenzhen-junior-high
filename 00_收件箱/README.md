# 收件箱

## 用途

所有通过微信、桌面或 Web 发来的原始资料，先进入这里，再分拣到台账各处。

## 目录

- `待处理/`：刚刚收到、还没分类的图片、文档、截图、语音转写等。
- `已处理/YYYY-MM-DD/`：当天处理完毕的原件和 `*.md` 摘录。
- `处理日志.md`：每个文件的处理去向、状态和待确认事项。

## 命名规则

原始文件统一建议命名：

```text
YYYY-MM-DD_HHmm_来源_学科_类型_简述.ext
```

示例：

- `2026-10-16_数学群_数学_作业要求_第二单元试卷.docx`
- `2026-10-16_家长_英语_错题_完形填空第3篇.jpg`
- `2026-10-16_班主任群_班级_通知_周五秋游.pdf`

## IM 插件建议配置

如果微信插件允许设置附件保存目录，建议指向：

```text
/Users/sambazhu/dshworkplace/朱秋宇初一学习台账/00_收件箱/待处理
```

如果插件只能把附件发到会话里，也没问题：在对话中说明是什么资料即可，我会先把它另存到收件箱，再按流程处理。

## 原件安全规则

- 不删除、不覆盖、不裁切原件；
- 需要 OCR 的图片，先复制一份再处理；
- 无法识别的内容标记 `❓待确认`，并保留原件等待补充。

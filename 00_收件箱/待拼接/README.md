# 待拼接

## 用途

微信里文字和附件经常分开发送，或者模型先看到文字、后看到附件，容易造成“割裂理解”。这里专门暂存**已经到达但还不能独立处理的文字线索**，等对应附件到达后合并成一次任务。

## 规则

- 只放文字线索，不放原件；原件仍放 `00_收件箱/待处理/`；
- 文件命名：`YYYY-MM-DD_HHmm_来源_待附件.md`；
- 文件到达后由 `im-intake` Skill 先扫描本目录，匹配最近 10—30 分钟内的线索并合并；
- 合并完成后，把待拼接文件移入 `00_收件箱/已处理/YYYY-MM-DD/`，并在 `处理日志.md` 记录；
- 超过 24 小时仍未匹配的，标注“待补充说明”，不删除。

## 目的

- 避免文字先到时立刻写正式错题/作业记录；
- 避免附件到达时模型只看到附件、不知道是哪一科、哪几题；
- 让“提示词 + 文件”最终合并成一条完整上下文。

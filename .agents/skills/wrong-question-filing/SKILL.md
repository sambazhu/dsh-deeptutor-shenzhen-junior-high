# 错题归档与复习计划

## 触发条件

- 家长发来错题照片、批改后的作业、试卷错题页；
- 老师讲解了某道题，家长转述或截图；
- 每日台账中发现需要重点记录的错题；
- 家长说“整理错题集”“把错题做成 Word”。

## 输入

- 错题图片/文档；
- 学科、来源（作业/周测/月考/期中/期末）、题号；
- 老师批改、答案、讲解；
- 孩子当时的答案或错因描述。

## 步骤

1. **识别基本信息**
   - 学科：语文/数学/英语/地理/历史/生物/道法；
   - 来源、日期、题号；
   - 知识点和错因；无法确定时标 `❓待确认`。

2. **保存原件**
   - 原图放对应学科 `0X_学科/错题集/原图/`；
   - 命名：`YYYY-MM-DD_来源_题号_知识点.jpg`；
   - 若已从收件箱归档，可在错题集目录保留副本。

3. **登记 Excel**
   - `成绩跟踪表.xlsx` →「错题跟踪」；
   - 字段：日期、学科、来源、题号/位置、知识点、错因分类、正确答案/解析摘要、是否掌握、计划复习日期、实际复习日期、备注。

4. **错因分类**
   - 概念不清 / 审题遗漏 / 计算错误 / 表达不规范 / 记忆不牢 / 方法不会 / 时间不够 / 其他；
   - 如果无法判断，写“待复盘确认”，不要随便归因。

5. **安排复习**
   - 默认间隔：D+1、D+3、D+7、D+15；
   - 每次复习后在 Excel 记录实际复习日期和是否掌握；
   - 同类知识点连续错 2 次以上，在每日建议中优先出现。

6. **追加到题库并生成 Word 错题集**（优先使用，2026-10-17 更新）
   - 源数据是 `0X_学科/错题集/题库.json`，新错题追加到 `questions` 数组；
   - 字段至少包含：id、date、source、type、topic、question、answer、explanation；
   - 答案/解析未验证时写 `❓待确认`，不得把模型猜测写入“正确答案”；
   - 运行 `python3 tools/build_wrongbook.py 学科`，自动生成/更新：
     - `0X_学科/错题集/输出/{学科}_错题练习_空白版.docx`（不含答案）
     - `0X_学科/错题集/输出/{学科}_错题练习_参考答案与讲解.docx`（含答案/解析）
     - 自动静默同步至 DeepTutor 知识库 `qiuyu-wrongbook` 并刷新伴学伙伴副本；
   - 不要手工编辑生成的 Word；每次从题库全量重建；
   - 详细字段见 `00_台账规范/错题集生成规范.md`。

7. **回复家长**
   - 说明已记录几道题、涉及哪些知识点、建议何时复习；
   - 如需孩子重做，给出具体题号和时间建议。

## 输出

- 错题原件与副本；
- Excel「错题跟踪」记录；
- 可选 Word 错题集；
- 复习提醒/建议。

## 边界

- 只根据照片和老师信息判断，不凭空补充题目条件；
- 解析如果不确定，标注“建议答案，待老师/家长核对”；
- 不直接把答案给孩子当“完成作业”，错题集的目的在于重做与讲清思路；
- 不删除原始错题照片。


## 附：文字先到、错题附件未到

如果家长只说“这个试卷错了 12、19、20 题”但附件未到：

- 不要把“12、19、20”直接写成正式错题条目；
- 先写入 `00_收件箱/待拼接/YYYY-MM-DD_HHmm_来源_待附件.md`；
- 等附件到达后由 `im-intake` 合并，再按本 Skill 正式登记；
- 合并前不得猜学科、知识点、错因和正确答案。

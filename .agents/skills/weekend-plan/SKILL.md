# 跨科排期与提醒去冲突

## 触发条件

- 家长一条消息里报来 **2 科以上**作业（例：“数学 4 页试卷，生物卷重做，历史 4 课背默，地理材料”）；
- 周末 / 假期的作业安排；
- 期中、期末前需要把多科复习排进有限天数；
- 已有排期但被新任务打乱，需要重排。

## 输入

- 当日台账与 `00_每日作业与待办/YYYY-MM/` 近期文件；
- 考试日程（`课程表.md` 里的校内课、家长口述的考试日期、既有复习计划）；
- `09_提醒工具/reminders.tsv`（现有提醒，用于查冲突）；
- `00_收件箱/处理日志.md` 的待确认项（哪些材料还没到）。

## 步骤

### 1. 先清点，再排（不排不知道总量）

列一张表，一条任务一行，能填的都填：

| 科目 | 任务 | 量 | 截止 | 预计 | 关联考试 |
|---|---|---|---|---|---|

- 缺的补 `❓`：卷名/页码不明、材料没到、课次不明；
- **材料没到的任务照排**，但在表里标「待材料」，不要空着不留位置。

### 2. 排优先级：三条硬规则

1. **按考试日期排，不按科目或难度排**（历史 11-05 早于生物/数学 11-06 → 历史先动手）；
2. **“作业即复习”的合并**：同一知识点的作业与复习算一件事（例：历史 4 课背默本身就是期中范围，不另加复习）；
3. **一天的净学习量 ≤ 3.5 小时，且留 20% 缓冲**：宁可排两天不满，也不要一天塞满后崩掉。

### 3. 估时分三档

| 档 | 时长 | 适合 |
|---|---|---|
| 长任务 | 35–45′ | 新卷、重做试卷、写作文 |
| 中任务 | 20–30′ | 背默、材料过一遍、专项 2–4 篇 |
| 短任务 | 10–15′ | 打卡、订正、抽背 |

### 4. 分到具体时段

- **上午攻坚**：长任务（新题、重做、套卷），一次 35–45′；
- **下午轮换**：中任务，且**相邻两段不同学科**（背完历史接着做数学，避免同科疲劳）；
- **晚上低耗**：英语阅读/打卡/订正，20–30′ 内结束；
- 课外班固定动作（朗读打卡）**拆成每天/隔天 10′**，绝不攒到最后一天。

### 5. 写回四处

1. **台账**：新增「校内周末作业」表 + 「两天排期」（哪天哪个时段做哪项，带时长）；
2. **Excel** `成绩跟踪表.xlsx` →「每日作业」：一项一行，备注写“排到哪天”；
3. **提醒** `09_提醒工具/reminders.tsv`：一个动作一条，格式
   `YYYY-MM-DD HH:MM<TAB>科目｜动作（时长）‖怎么做/怎么检查`；
4. **冲突检查**（必须跑）：
   ```bash
   python3 tools/check_reminder_conflicts.py
   ```
   - 报「同刻重复」→ 错开至少 15 分钟；
   - 报「间隔过短」→ 把短任务挪走或合并；
   - 报「已过期」→ 按 v0.13 **不追**，删掉或忽略。

### 6. 给家长的东西

- 两天（或三天）时间表：时段 + 科目 + 时长；
- **建议 ≤3 条**，每条落到“哪天做、做多少、怎么检查”；
- **缺口清单**：还缺哪些材料/信息（缺卷子、缺材料、课次不明），一条一句。

## 输出

- 台账的周末作业表与排期表；
- Excel「每日作业」新增行；
- 更新后的 `reminders.tsv`（无冲突）；
- 给家长的时间表 + 3 条建议 + 缺口清单。

## 边界

- **不为了塞满而加任务**：宁可留白，也不排“看起来很努力”的计划；
- 一次排期最多覆盖 **3 天**，更长的拆成多次；
- 不猜未知项（卷名、题量、材料内容）——标 ❓ 并问；
- 已过期任务按 v0.13 不追，不排进新计划；
- 学生实际完成情况以家长口述为准，估时偏差大时下次按实际回调（记在台账备注里）。

# IM 资料收件与分拣

## 触发条件

- 家长在微信/会话里发来图片、文件、截图、语音转写；
- 工作区根目录或 `00_收件箱/待处理/` 出现新的原始资料；
- 家长只说“你帮我看看这个”，但没说是什么类型。

## 输入

- 会话附件、文件路径或工作区新文件；
- 家长随文件发来的一句话说明；
- 当前日期与星期。

## 步骤

1. **落盘原件**
   - 复制/保存到 `00_收件箱/待处理/`；
   - 文件名：`YYYY-MM-DD_HHmm_来源_学科_类型_简述.ext`；
   - 若原件已在项目内，先登记路径，不重复复制大文件。

2. **判断类型**

   | 类型 | 典型线索 | 下一步 |
   |---|---|---|
   | 作业要求 | “今晚作业”“明天交”“完成练习册” | 交给 `daily-ledger` |
   | 班级通知 | 时间、地点、要带物品、活动 | 写入当天台账待办/明日提醒 |
   | 错题 | 红叉、订正、题目照片 | 交给 `wrong-question-filing` |
   | 试卷/成绩 | 分数、排名、试卷头、答题卡 | 交给 `exam-analysis` |
   | 其他 | 无法判断 | 留待确认，向家长问一句 |

3. **提取文字**
   - 图片/PDF：先尝试 OCR 或视觉识别；
   - Word/Excel：直接读取文本或表格；
   - 生成同名 `.md` 摘录文件，放在原件旁边；
   - 识别不确定的字词用 `❓` 标出，不猜测。

4. **路由**
   - 当日作业/通知 → 更新 `00_每日作业与待办/YYYY-MM/YYYY-MM-DD_周X.md`；
   - 错题 → 对应学科 `错题集/` + Excel「错题跟踪」；
   - 成绩/试卷 → Excel「成绩总览」+ `0X_学科/考试与测验/`；
   - 无法归类 → 留在待处理，写处理日志并询问家长。

5. **归档**
   - 处理完成后，将原件和摘录移到 `00_收件箱/已处理/YYYY-MM-DD/`；
   - 在 `00_收件箱/处理日志.md` 追加一行；
   - 不删除原件。

6. **回报**
   - 一句话说明：收到了什么、分到哪里、还有什么待确认；
   - 如果有多份资料，用列表列清楚。

## 输出

- `00_收件箱/` 中的原件与 `.md` 摘录；
- 处理日志一行；
- 对应台账文件的更新；
- 给家长的简短回执。

## 边界

- 不要为了“整理干净”删除、覆盖或裁掉原件；
- OCR 把握不大时保留原文并标 `❓`；
- 不要根据截图外观猜学科，学科不确定就先问；
- 不把资料内容发送到项目以外。


## 六、文字与附件分离时的合并规则（2026-10-16 新增）

微信里文件与提示词可能分两条到达，甚至附件下载慢、模型先看到提示词。按下面规则避免“割裂理解”。

### A. 文字先到、附件未到

当纯文字消息出现以下情况时，不要立刻当完整任务处理：

- 出现“这个/这份/那张/刚发/稍后/上面/附件/试卷/图片/照片/文件”等指代；
- 提到“我发给你/我要发的/刚发的那张”；
- 缺少主语或学科，无法独立整理成正式记录。

处理：

1. 不马上写正式错题本、考试记录或每日作业；
2. 写入 `00_收件箱/待拼接/YYYY-MM-DD_HHmm_来源_待附件.md`（按 `模板_待拼接文字.md`），保留家长原话；
3. 只回一句轻提示：“收到上下文，等附件到后我一起处理。”不要连着追问多个问题；
4. 如果家长追问，按普通问答处理；附件到达后仍然合并。

但如果文字本身可以独立处理（例如“今天数学作业是练习册第 10 页”），正常走 `daily-ledger`，不要挂起。

### B. 附件先到、没有说明

附件到达时：

1. 先扫描 `00_收件箱/待拼接/`，找最近 10—30 分钟内、同一来源、未匹配的文字线索；
2. 若找到，读出线索原文，把附件与线索合并后再处理，并把待拼接文件移入 `00_收件箱/已处理/YYYY-MM-DD/`；
3. 若没有可匹配线索，不要猜学科和错因；在 `00_收件箱/待拼接/` 建 `_待上下文` 记录，原件保留在 `00_收件箱/待处理/`；
4. 只回一句：“文件已收到。请补一句：哪一科、是什么资料（作业/试卷/错题）？”
5. 拿到说明后再正式处理。

### C. 文件与文字同一条消息

直接按正常 `im-intake` 流程处理，不需要进入待拼接。

# 机构课材料归档（蓝天英语 / 蓝天数学）

## 触发条件

- 家长转发蓝天英语、蓝天数学老师的微信：课前通知、课上内容、本课作业、点名/提醒；
- 发来「课次 N」成绩表（全班名单那张 Excel 截图）；
- 发来 ClassIn 朗读打卡链接（通常是三条）；
- 出现关键词：`课次`、`宝典`、`AEG`、`真题卷`、`朗读打卡`、`ClassIn`。

## 输入

- `课程表.md` →「课外班固定安排」（上课时间、打卡截止规则）；
- 该机构上一节课的 `03_英语/作业记录/`、`03_英语/考试与测验/` 记录；
- `成绩跟踪表.xlsx` →「成绩总览」「每日作业」；
- 当天 `00_每日作业与待办/YYYY-MM/YYYY-MM-DD_周X.md`（没有就按 `daily-ledger` 建）；
- 家长这一条消息的原文（全文照抄，不改写）。

## 步骤

### 1. 先判材料类型，一类一个落点

| 材料 | 落点 | 备注 |
|---|---|---|
| 课上内容 / 老师通知 | `03_英语/作业记录/YYYY-MM-DD_蓝天英语第N课反馈通知.md` | 原文＋事实/推理分层＋待确认 |
| 本课作业清单 | 当日台账「蓝天英语第 N 课作业」表 + Excel「每日作业」 | 每项一行：页码、要求、预计用时 |
| 课次成绩表（全班名单） | `03_英语/考试与测验/YYYY-MM-DD_..._课次成绩表分析.md` + Excel「成绩总览」 | 走 `exam-analysis` 的分项分析 |
| 朗读打卡链接 | `03_英语/作业记录/YYYY-MM-DD_WeekN朗读打卡_链接与截止.md` | 记链接、截止、排期 |

原件先落 `00_收件箱/待处理/`，命名 `YYYY-MM-DD_HHmm_来源_学科_类型_简述.ext`，处理完移 `00_收件箱/已处理/YYYY-MM-DD/`，并在 `00_收件箱/处理日志.md` 加行。

### 2. 材料不全先占位，不要下结论（今天踩过的坑）

- 只收到「学习内容」、还没收到「本课作业」时：台账写 **「本课作业：❓待老师发」**，**不要写**“本课只布置了 X 一项”；
- 只收到作业、没有成绩表时：正常写作业，成绩部分留空；
- 拿不准就写 `❓待确认` 并问一句，不补脑。

### 3. 成绩表必做「口径三问」（每次都要过一遍）

1. **满分是多少？**（把各分项分值加起来核对，不一致就说明有分项没录）
2. **分值怎么构成？**（第 7 课 = 默写 100+完型 10+语填 10+阅读 5+释义 30 = 155；第 8 课 = 真题卷 60+语填 20+阅读 5+词法 40+六选五 10 = 135）
3. **表里的「朗读打卡 / 课后作业」是哪一周的？**
   - 规则：**课次 N 成绩表里的作业栏 = 第 N-1 次课布置的**，同栏的「朗读打卡 1/2/3」也属 **Week N-1**；
   - 验证方法：看左栏作业内容是否就是上一节课布置的（对得上即可确认）；
   - 全班名单里有人写「没带/未完成」时，该分项的班均不含这些人的 0 分，算班均要说明。

**不同课次的满分不同时，总分不可直接横比**，只比得分率与分项位置，并在分析文件顶部写清口径。

### 4. 成绩分析的取数（交给 exam-analysis 写）

- 逐项：满分、得分、班均、差、得分率、全班位置（第几/并列第几）；
- 排名：按总分降序自己数一遍，不抄老师口头；
- 与上次同一机构对比时：**只比同一知识点的得分率**（例：语填 4/10→16/20），不比总分；
- 全班执行面单独一节：作业签名率、朗读打卡提交情况（这些是零成本分）。

### 5. 朗读打卡：链接、截止、排期

- 平台 = **ClassIn**（AI 口语卡跟读）；
- **截止 = 上课前**；蓝天英语每周六 09:00 上课，系统显示 **08:30**；
- 建链接表：三次一组，写清「第几次 / 链接 / 截止」，并注明这是 Week N、与上一周 Week N-1 是两套；
- 排期原则：**不要排在截止当天早上**（要准备上课），拆成周六/周日/周中各一次，每次单独提交（老师按 1/2/3 分别计分）；
- 每次 10 分钟，写进 `09_提醒工具/reminders.tsv`。

### 6. 过期项按 v0.13 处理

已过截止的打卡/作业：**不补做、不提醒、不进建议、不问老师能否补交**，台账里标一次「⚠️ 已过期·不追」留痕即可。

### 7. 收尾（每类材料都要走完）

- 当日台账：新增或更新对应章节；
- `成绩跟踪表.xlsx`：「每日作业」每项一行；成绩类写「成绩总览」；
- `09_提醒工具/reminders.tsv`：每个动作一条，格式 `YYYY-MM-DD HH:MM<TAB>科目｜动作（时长）‖怎么做/怎么检查`；写完跑 `python3 tools/check_reminder_conflicts.py` 查同刻冲突；
- `00_收件箱/处理日志.md`：加一行（时间/来源/文件/类型/处理/归档/状态）；
- 回复家长：收到什么、归到哪、还差什么。

## 输出

- 反馈通知 md、成绩分析 md、打卡链接表（按需）；
- 当日台账 + Excel 两次更新 + 提醒；
- 给家长的一段「这周怎么样 + 三条怎么做」。

## 边界

- 不猜满分、分值构成、打卡归属周次；
- 不同口径的分数不横比，不承诺提分数字；
- 不主动发微信（除非家长要求回传文件）；
- 家长口述的分数与老师表冲突时，两个都记，标 `❓以哪个为准`，不擅自取舍。

# 周复盘

## 触发条件

- 周日晚上或周一早上；
- 家长说“周复盘”“这周怎么样”“下周怎么安排”；
- 需要检查本周遗留任务与重复错题时。

## 输入

- 本周 `00_每日作业与待办/YYYY-MM/YYYY-MM-DD_周X.md`；
- `成绩跟踪表.xlsx` 三个工作表；
- `0X_学科/错题集/` 和考试分析；
- 家长补充的观察。

## 步骤

1. **汇总事实**
   - 本周作业完成率、未完成项、拖延最多科目；
   - 各科错题数量、重复知识点；
   - 成绩变化（只做同科同类型对比）。

2. **找规律**
   - 哪些问题是偶发，哪些是重复出现；
   - 什么时间段效率低、哪科作业耗时异常；
   - 家长配合层面的可调整点。

3. **输出周复盘**
   - 位置：`00_每日作业与待办/YYYY-MM/周复盘_YYYY-MM-DD.md`；
   - 结构：
     - 本周概览（完成情况、测验成绩）
     - 做得好的 3 件事
     - 需要改进的 3 件事（按影响排序）
     - 下周 3 个动作（具体到科目、时间、检查方式）
     - 家长配合事项（最多 2 条）

4. **检查规则**
   - 如果某个问题连续两周出现，提出对 Skill 或使用习惯的调整，写入 `00_台账规范/迭代记录.md`；
   - 如果目标连续未完成，降低目标难度或减少数量，而不是简单重复要求。

5. **可选回传**
   - 家长要求时，将周复盘 Markdown 回传微信。

## 输出

- 周复盘 Markdown；
- 下周计划；
- 必要时一条规则调整记录。

## 边界

- 周复盘不是“错误清单”，也要记录有效的学习行为；
- 建议数量克制：3 个动作以内；
- 不用分数排名作为唯一评价标准。

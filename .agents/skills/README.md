# 项目 Skills

本目录用于维护朱秋宇学习台账的可复用工作流。每个 Skill 一个文件夹，主文件为 `SKILL.md`，格式与全局 Skill 规范保持一致：frontmatter + 触发条件 + 输入 + 步骤 + 输出 + 边界。

## 当前 Skills

| Skill | 解决的问题 | 触发场景 |
|---|---|---|
| `im-intake` | 微信/会话附件的落盘、识别与初步路由 | 收到图片、文档、群通知、成绩单、错题照片 |
| `daily-ledger` | 生成和维护每日作业、待办与建议 | 发来当天作业、说“今日汇总” |
| `wrong-question-filing` | 错题归档、知识点标注、复习计划 | 发来错题照片、批改作业、试卷错题 |
| `exam-analysis` | 成绩记录、趋势分析和考试复盘 | 发来分数、排名、试卷、答题卡 |
| `weekly-review` | 一周汇总与下周计划 | 周日或说“周复盘” |

## 修改约定

- 先读：`AGENTS.md`、`00_台账规范/工作流.md`、相关 `SKILL.md`；
- 每个 Skill 只解决一个目标，步骤要能在一次会话内走完；
- 修改后同步更新 `00_台账规范/迭代记录.md`；
- 详细材料放 `references/`，示例放 `examples/`，不要往主文件堆事实。

# 考试成绩记录与分析

## 触发条件

- 家长发来分数、排名、等级、平均分；
- 发来试卷、答题卡、成绩单截图；
- 家长问“这次考得怎么样”“怎么提高”；
- 每日台账中出现考试/测验信息。

## 输入

- 学科、考试名称、考试类型、日期；
- 满分、得分、班级排名、年级排名；
- 各题失分、错题知识点、老师评语；
- 历史成绩记录（Excel「成绩总览」）。

## 步骤

1. **提取并核对字段**
   - 缺什么标 `❓待确认`，不推测；
   - 注意满分是否 100/120/150，按实际记录。

2. **写入 Excel**
   - `成绩跟踪表.xlsx` →「成绩总览」；
   - 日期、学科、考试名称、类型、满分、得分、得分率（表内公式自动算）、班级排名、年级排名、主要失分点、后续措施、备注。

3. **保存试卷与分析**
   - 试卷/答题卡原件放 `0X_学科/考试与测验/`；
   - 写分析文件：`YYYY-MM-DD_考试名称_分析.md`。

4. **对比最近成绩**
   - 至少看同科最近 3 次；
   - 分数变化必须结合试卷难度、考试类型说明，不能只看涨跌；
   - 排名缺失时不比较排名。

5. **定位失分**
   - 从错题、扣分题、老师评语中找 3 个以内主要问题；
   - 关联到知识点（如“有理数混合运算顺序”“英语一般现在时第三人称单数”）；
   - 检查是否与 Excel「错题跟踪」中的重复错误一致。

6. **生成复盘与建议**
   - 分析文件包含：成绩概览、与上次对比、失分类型、3 个问题、3 个行动、复习时间；
   - 行动要具体到“哪天做什么、做多少、怎么检查”；
   - 不因一次低分否定孩子，优先找可控因素。

7. **回传**（家长要求时）
   - 可将分析 Markdown 生成后回传微信；
   - 回传前确认内容不含不必要的敏感信息。

## 输出

- Excel「成绩总览」记录；
- `0X_学科/考试与测验/YYYY-MM-DD_考试名称_分析.md`；
- 家长可读的成绩分析摘要与建议。

## 边界

- 不把不同科目、不同满分、不同难度的分数直接横向比较；
- 排名、平均分缺失不猜测；
- 不承诺提分数字；
- 不因单次成绩建议大量刷题；建议优先针对重复错因。

数轴上两点间的距离 与 绝对值的几何意义

教材依据：北师大版七年级上册 第二章《有理数及其运算》 对应页码：P29（数轴）、P34（绝对值）、P37（绝对值的几何意义）、P48 习题第 22 题 适用：深圳初一（七年级上）期中复习

学习目标

  1. 说清 |a − b| 就是数轴上 a、b 两点间的距离，并知道为什么不是 a − b；
  2. 从「绝对值＝到原点的距离」推出「|x − a|＝x 到 a 的距离」；
  3. 会用距离公式解决三类题：求距离、已知距离求点、数轴动点；
  4. 记住四个高频易错点，考试不再丢冤枉分。

一、教材原话（先看课本怎么说）

  • P29：规定了原点、单位长度、正方向的直线叫数轴；任何一个有理数都可以用数轴上的一个点表示。

关键一句：数轴上右边的数总比左边的数大。

  • P34：绝对值表示这个数「有多大」，不计正负。5 与 −5 的绝对值都是 5。
  • P37：「表示互为相反数的两个点，位于原点的两侧，且到原点的距离相等。一个数的绝对值就是这个数所对应的点到原点的距离。」
  • P48 习题 22：给 a、b 的值求两点距离，再要求「用 a、b 表示 A、B 两点间的距离」——答案就是 |a − b|。

结论先摆出来，但先别急着背： AB = |a − b| = |b − a|，而 |x − a| 就是「x 到 a 的距离」。 这两句话是同一个道理的两个说法。

二、推导链条：四段相扣

第 1 段：|x| 是点 x 到原点 0 的距离

|5| = 5（原点右边 5 格），|−5| = 5（原点左边 5 格），|0| = 0。

距离恒 ≥ 0，这正好解释了绝对值不可能为负。

第 2 段：把「原点」搬到 a 上——平移不改变距离

现在问「x 到 a 的距离」，原点不在 a 上，第 1 段不能直接用。

办法：让整条数轴上每个点表示的数都减去 a（相当于整条数轴平移 a 个单位）。

  • 点 a 变成 a − a = 0，落到原点；
  • 点 x 变成 x − a。

跨度不变，于是：

x 到 a 的距离 = |(x − a) − 0| = |x − a|

这就是 |x − a| 的全部理由。

自检：取 a = 0 得 |x|，正好退回第 1 段；取 x = a 得 0，同一点到自身距离为 0。

第 3 段：验证 |a − b| 就是两点距离（分三种情形）

按 P29「右边的数减左边的数」，再验证它与 |a − b| 一致：

情形右减左（距离）|a − b|是否一致
a < bb − a−(a − b) = b − a✓
a > ba − ba − b✓
a = b00✓

三种情形穷尽所有可能，所以对任意 a、b：

AB = |a − b| = 右边的数 − 左边的数（≥ 0）

这一步同时回答了「为什么必须加绝对值」：a − b 可能是负数，而距离不能是负数，绝对值的作用就是去掉符号、只留跨度。

第 4 段：为什么 |a − b| = |b − a|

  • 代数上：b − a = −(a − b)，互为相反数的两数绝对值相等（P37）；
  • 几何上：A 到 B 的路程等于 B 到 A 的路程。

⚠️ 使用提醒：绝对值里面谁减谁随意（结果相同）；绝对值外面不能漏（漏了可能是负数）。

副产品：中点公式

由 |m − a| = |b − m| 得：

m = (a + b) / 2

这正是「数轴折叠使两点重合」题里折痕表示的数。

三、例题（由易到难）

例 1（基础）求距离 + 已知距离求坐标

A 表示 −3，B 表示 5。 （1）求 AB；（2）P 表示 x，PA = 4，求 x。

思路

  • （1）套公式；
  • （2）把「距离 4」翻译成 |x − (−3)| = 4，绝对值方程一般两解。

规范步骤

AB = |−3 − 5| = |−8| = 8

|x + 3| = 4 ⟹ x + 3 = 4 或 x + 3 = −4 ⟹ x = 1 或 x = −7

检验：|1 + 3| = 4 ✓；|−7 + 3| = 4 ✓

答案：AB = 8；x = 1 或 x = −7。

易错提醒：只写 x = 1。凡「到某点距离 = d」且 d > 0，必两解；d = 0 才一解。写完画个小轴点一下，10 秒能查漏。

例 2（中档）含绝对值化简与分类讨论

化简 |x − 2| + |x + 1|，分 x < −1、−1 ≤ x ≤ 2、x > 2 三种情形。

思路

两个绝对值，关键在去符号，规矩是「先判断里面正负」。分界处就是让每个绝对值 = 0 的 x（零点）：x = 2、x = −1，把数轴切成三段，每段内部符号固定。

分类不是老师规定的，是符号真的会变。

规范步骤

① x < −1 时：|x − 2| = 2 − x，|x + 1| = −(x + 1) = −x − 1，和为 1 − 2x。

② −1 ≤ x ≤ 2 时：|x − 2| = 2 − x，|x + 1| = x + 1，和为 3。

③ x > 2 时：两者皆正，和为 (x − 2) + (x + 1) = 2x − 1。

答案

  • x < −1：1 − 2x
  • −1 ≤ x ≤ 2：3
  • x > 2：2x − 1

几何看法：原式是「x 到 2 与到 −1 的距离之和」。x 落在线段上时两段拼成整条线段，和恒为 |2 − (−1)| = 3；跑出外侧则多走来回，和变大。所以最小值是 3，不是 0——这常是采分点。

易错提醒

① 去绝对值不加括号（写成 x + 1，实际 x + 1 < 0，负数的绝对值是它的相反数，须整体加括号变号）； ② 端点漏掉（写成 −1 < x < 2，丢了 x = −1、2，应让端点归中段、三段首尾相接）； ③ 只会算不会说最小值。

例 3（稍难）数轴动点与距离

A = −6，B = 10。P 从 A 向右每秒 2 个单位，Q 从 B 向左每秒 1 个单位，时间 t > 0。

（1）用 t 表示 P、Q；（2）求 PQ；（3）PQ = 4 时求 t；（4）何时 PQ 最小。

思路（动点三句话）

① 写坐标（起点 + 有向路程）； ② 写距离（一律写成差的绝对值，别急着判左右）； ③ 令绝对值里面 = 0 找相遇时刻作分界点。

规范步骤

（1）P = −6 + 2t，Q = 10 − t。

（2）PQ = |P − Q| = |(−6 + 2t) − (10 − t)| = |3t − 16|。

（3）|3t − 16| = 4 ⟹ 3t − 16 = 4 或 3t − 16 = −4 ⟹ t = 20/3 或 t = 4。

两解含义不同：t = 4 时 P = 2、Q = 6（P 未追上）；t = 20/3 时 P = 22/3、Q = 10/3（P 已超过）。

检验：|22/3 − 10/3| = 4 ✓

（4）|3t − 16| ≥ 0，取 0 当 t = 16/3，两点相遇于 14/3（P：−6 + 2 × 16/3 = 14/3；Q：10 − 16/3 = 14/3，一致 ✓）。

答案：（1）P = −6 + 2t，Q = 10 − t；（2）PQ = |3t − 16|；（3）t = 4 或 20/3；（4）t = 16/3 时 PQ 最小，最小值 0。

易错提醒

① 漏绝对值写成 3t − 16，t > 16/3 后算出负距离，第（3）问丢解； ② 以为只追上一次（P 更快，会两次「相距 4」）； ③ 用「右减左」却忘了左右会换。

与错题本的呼应：MATH-20261016-20 中 AB = |3t − 5|、分界 t = 5/3、分段讨论，与本题完全同构；那道题的「折叠重合」用的就是中点公式 (a + c) / 2。

四、四个高频易错点

#错法为什么错怎么避免
1直接写 a − b 当距离a − b 可能为负，而距离不能为负固定写 |a − b|；或先比大小用「右减左」，两种情况结果一致
2去绝对值不加括号变号（x < −1 时把 |x + 1| 写成 x + 1）|x + 1| = −x − 1，少了这个括号，符号会整体相反去符号前先判一次正负，负的整体加括号再取相反数
3|x − a| = d 只写 x = a + d到 a 距离 d 的点在左右各一个，漏掉 a − d见「距离 = d > 0」立刻提醒自己两解，画轴标点复核
4动点题不设分界点，把 |3t − 16| 当成 3t − 16越过相遇时刻，绝对值里面变号，式子性质整体改变先令里面 = 0 求相遇时刻，再分两段讨论并写明「当…时」

五、自测题（孩子先做，家长先别展开）

T1（基础）

数轴上 A 表示 −2，B 表示 6。

  1. 求 AB；
  2. 点 P 表示 x，且 PA = 3，求 x；
  3. 点 Q 表示 y，且 QA = QB，求 y。

T2（中档）

化简 |x − 3| + |x + 2|。

  1. 写出 −2 ≤ x ≤ 3 时的结果，并说明这个结果为什么是常数；
  2. 求原式的最小值；
  3. 若原式 = 7，求 x。
答案参考答案（点开查看）

T1

1. AB = |−2 − 6| = 8。

2. |x + 2| = 3 ⟹ x = 1 或 x = −5。（提示：两解，左 3 格与右 3 格）

3. y 到 −2 与到 6 距离相等 → y 是中点 = (−2 + 6) / 2 = 2。

T2

1. 此时 x − 3 ≤ 0、x + 2 ≥ 0，原式 = (3 − x) + (x + 2) = 5。因为 x 落在线段上，两段拼成整条线段，长度恒为 |3 − (−2)| = 5。

2. 最小值 5（在 −2 ≤ x ≤ 3 上处处取到）。

3. x = 4 或 x = −3。（提示：7 > 5，点在线段外侧各一处；验算 |4 − 3| + |4 + 2| = 1 + 6 = 7 ✓，|−3 − 3| + |−3 + 2| = 6 + 1 = 7 ✓）

六、一句话总结

数轴上两点距离 = 坐标差的绝对值；绝对值 = 到定点的距离。 遇到「距离」先写绝对值，遇到绝对值先想「到哪一点的距离」，遇到多解先问「是不是有两个点」。

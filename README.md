## 二、微信 IM 上传怎么用

微信插件的工作区已经指向本项目。推荐流程：

```text
微信里发：文件/截图 + 一句话说明
        ↓
00_收件箱/待处理/（原件落盘）
        ↓
自动识别资料类型并提取文字
        ↓
每日台账 / 错题跟踪 / 成绩总览 / 待办清单
        ↓
00_收件箱/已处理/YYYY-MM-DD/（归档，原件不删除）
```

如果插件支持设置附件保存目录，建议直接指向：

```text
/Users/sambazhu/dshworkplace/朱秋宇初一学习台账/00_收件箱/待处理
```

如果不支持，直接发到微信里也可以，我会先另存到收件箱再处理。

微信附件下载可能比文字慢。推荐顺序：

1. **先发文件**；
2. 等机器人回一句“文件已收到”或几秒钟；
3. **再发提示词**，例如“这是数学试卷，第 12、19、20 题孩子做错了”。

如果先发了提示词、文件后到，也没关系：提示词会先放入 `00_收件箱/待拼接/`，文件到达后自动合并，不会马上写正式记录。

## 三、每天可以帮你做什么

1. **整理每日作业**：按学科拆分、标注预计用时、生成待办清单。
2. **记录考试与成绩**：更新 `成绩跟踪表.xlsx`，计算得分率，对比近几次变化。
3. **跟踪错题**：按“知识点 + 错因”归类，安排 D+1、D+3、D+7、D+15 复习。
4. **给出针对性建议**：根据作业正确率、考试失分点和错题分布，给第二天/本周的小目标。
5. **周末/考前汇总**：生成一周学习分析，明确薄弱点和下周计划。
6. **按需回传**：需要时可以把日报、周报、错题 Word 回传到微信。

## 八、错题集 Word 输出（2026-10-17 新增）

每个学科维护 `0X_学科/错题集/题库.json`，运行：

```bash
python3 tools/build_wrongbook.py 数学
```

会自动生成两份 Word：

- `数学_错题练习_空白版.docx`：只有题目和答题区，适合打印重做；
- `数学_错题练习_参考答案与讲解.docx`：答案速查 + 解析 + 错因 + 变式。

详细规范见 `00_台账规范/错题集生成规范.md`。新增错题只需要追加题库，再重新运行生成命令。

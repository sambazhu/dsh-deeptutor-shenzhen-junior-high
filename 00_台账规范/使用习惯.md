# 家长使用习惯与规范

## 一、最省力的使用方法

不需要每次都写得很正式，也不用攒到晚上才发。推荐：

```text
[转发/截图/文件] + 一句话说明
```

例如：

- 老师群通知截图 → “英语老师发的，周五听写 Unit 3。”
- 错题照片 → “数学错题，第二单元，错了符号。”
- 成绩单 → “数学周测 85/100，班级第 12。”
- 作业 → “今晚语文、数学、英语作业分别是……”
- 不确定 → 直接发文件，我会识别；识别不了会问你。

**最好包含的三样信息**：学科、来源、要求。没有也没关系，先发原件，我来整理。

## 二、建议节奏

| 时间 | 动作 | 目的 |
|---|---|---|
| 白天随时 | 看到老师发通知/孩子错题就转发 | 不遗漏、不积压 |
| 18:00—20:00 | 发当天作业、成绩、完成情况，或说“今日汇总” | 生成日报和明日待办 |
| 周日晚上 | 说“周复盘” | 总结一周薄弱点，定下周计划 |
| 大考后 | 发试卷/成绩/排名 | 做考试分析 |
| 任何时候 | 告诉我规则不合适 | 迭代 Skill 和使用规范 |

## 三、关于拍照和文件

- 试卷、作业照片尽量拍全：卷头、题号、分数、批改痕迹；
- 多张同科照片连续发即可，我会按同一批处理；
- 有标准答案、老师解析、班级群通知，一并发；
- 文件格式不限：jpg/png/pdf/docx/xlsx 均可；语音/视频也可以，我会先转写或标记。

## 四、助手会做什么

1. 自动识别资料类型并归档；
2. 每天更新作业、待办和错题；
3. 记录成绩、计算得分率、看变化趋势；
4. 根据错题和成绩给针对性建议；
5. 每周汇总，指出重复出错的知识点；
6. 需要时把日报、周报或错题 Word 回传到微信。

## 五、助手不会做什么

- 不会主动在微信发消息或催你，需要你发起；
- 不会删除你的原始文件；
- 不会编造成绩、排名或老师要求；
- 不会一次给一大堆建议；每天最多 3 条，抓重点。

## 六、信息隐私

所有学生资料只保存在本项目文件夹内，不外传、不用于其他用途。成绩和排名属于敏感信息，请不要在公开群里发送。


## 七、文件和文字说明最好一起发

- 最顺的方式：**同一条消息里带文件 + 一句说明**；
- 如果分开发，建议先发文件，再补文字：“这是数学试卷，错的 12、19、20 题”；
- 如果文字先发、文件后到，我会先建 `_待附件` 占位，等文件到了再合并；期间不会把猜测写成正式记录；
- 家长若发了照片/PDF，最好带上“哪一科、哪几题错了、老师有没有批改”三个信息。


## 八、文件与文字分两条发时的顺序

微信附件下载有时比文字慢，如果模型先看到文字，容易产生“只有半句”的理解。推荐：

1. **先发文件**，等机器人回一句“文件已收到”或稍等几秒；
2. **再发提示词**，例如“这是数学试卷，第 12、19、20 题孩子做错了”；
3. 如果先发了提示词，后补文件，也没关系：机器人会先把提示词放到 `00_收件箱/待拼接/`，等文件到后自动合并，不会马上写错。

最顺的格式：

```text
[先发文件]
（等几秒或等机器人确认）
“数学试卷，第 12、19、20 题，老师红笔批改过，帮我登记错题”
```

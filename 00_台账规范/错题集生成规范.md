# 错题集 Word 生成规范

> 2026-10-17 建立。目标：错题可以不断新增，但始终输出两份干净的 Word：
> 1. **空白练习版**：只有题目和答题空间，没有答案、没有解析；
> 2. **参考答案与讲解版**：答案、解析、错因提醒、变式练习。

## 一、原则：Word 是输出，题库是源文件

不要手工编辑生成的 Word，也不要把答案写进空白版。每次新增错题后，由脚本从题库重新生成两份 Word。

```text
0X_学科/错题集/题库.json        ← 源数据，持续追加
        ↓
python3 tools/build_wrongbook.py 学科
        ↓
0X_学科/错题集/
  ├── {学科}_错题练习_空白版.docx
  └── {学科}_错题练习_参考答案与讲解.docx
```

这样新增题目不会破坏原有格式，也不会出现“空白版里混入答案”的情况。

## 二、题库结构

每个学科一个：

```text
0X_学科/错题集/题库.json
```

模板见：`00_台账规范/模板_错题题库.json`

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 建议 | 唯一编号，例如 `MATH-20261016-19C` |
| `date` | 是 | 错题日期 `YYYY-MM-DD` |
| `source` | 是 | 来源：哪份试卷/作业/测验 |
| `type` | 建议 | 填空/选择/解答/实验/材料题等 |
| `topic` | 是 | 知识点 |
| `question` | 是 | **只放题目正文，不能放答案或提示** |
| `question_images` | 否 | 图片路径，相对 `错题集/` 目录，例如 `原图/xxx.png` |
| `blank_lines` | 建议 | 空白答题行数，默认 8；解答题可设 12—18 |
| `answer` | 是 | 参考答案；不确定写 `❓待确认`，不得猜 |
| `explanation` | 是 | 详细解析，可多段 |
| `mistake_reason` | 否 | 错因提醒/复盘重点，不要写答案提示到空白版 |
| `variant` | 否 | 同类变式，可留空 |
| `status` | 否 | 待复习 / 已掌握 / 待确认 |

## 三、新增一道错题的流程

1. 从收件箱/卷面确认：学科、来源、题目、答案、解析；
2. 若答案或解析没有把握，先标 `❓待确认`，等老师/家长确认后再入库；
3. 在对应 `题库.json` 的 `questions` 数组末尾追加一个对象；
4. 运行：

```bash
cd /Users/sambazhu/呱呱/朱秋宇初一学习台账
/Users/sambazhu/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/python/bin/python3 tools/build_wrongbook.py 数学
```

也可以一次重建所有已有题库的学科：

```bash
python3 tools/build_wrongbook.py --all
```

5. 检查 `0X_学科/错题集/` 里两份 Word 是否更新；
6. 在 `00_收件箱/处理日志.md` 记录新增了哪几题。

## 四、排版约定

- A4 纸，2 cm 左右页边距；
- 每个大题默认单独起一页，便于打印和重做；
- 空白版：题号、来源、知识点、题型、题目、答题区、答案横线、错因填写行；
- 答案版：答案速查表 + 题目回顾 + 答案 + 解析 + 错因提醒 + 变式；
- 一题一对象；多小问如果互相关联，放在同一个对象里；如果独立成题，可拆成多个对象并给不同 id。

## 五、多学科扩展

- 目前先为数学建了题库并生成样例；
- 其他学科首次有错题时，复制 `模板_错题题库.json` 到对应 `0X_学科/错题集/题库.json`，修改 `subject` 后追加题目，再运行生成命令；
- 不建议把七个学科硬塞进同一个 Word，以免打印时太重；如需“全科合集”，后续可以再加一个汇总脚本。


## 六、有图题目的扣图规则（2026-10-17 新增）

第 20 题这类有数轴、几何图形、统计图的题目，**必须带原题图**，否则孩子看不懂题。

### 处理步骤

1. 找到原始 PDF/照片（优先使用 `00_收件箱/已处理/` 的原件）；
2. PDF 先按页渲染，例如 300 dpi：

```bash
pdftoppm -f 7 -l 7 -r 300 -png 原卷.pdf /tmp/page
```

3. 只裁题目文字和图形区域，**不要裁到下方“解：”开始后的答题/解析内容**；
4. 如果卷面有红笔/蓝笔批注，可用颜色过滤把红/蓝手写去掉，保留黑色印刷题目；
5. 保存到：

```text
0X_学科/错题集/原图/YYYY-MM-DD_第N题_原题图.png
```

6. 在 `题库.json` 对应题目里设置：

```json
"question_display": "（原题文字与图形见下图；请把解答写在下方答题区。）",
"question_images": ["原图/YYYY-MM-DD_第N题_原题图.png"]
```

7. 重新生成 Word。

### 原则

- 空白版里的题目图不能包含答案、解题过程或明显提示；
- 如果手写内容无法完全清理，就只抠纯图形（数轴、几何图、表格），题干文字用 Word 录入；
- 图片在 Word 中按页面宽度自动缩放，不拉伸变形；
- 每道题可以放多张图；题干文字多时，图放在题目文字后面。
